1. โปรแกรมนี้คืออะไร (และไม่ใช่อะไร)

เป็นเครื่องมือคำนวณและจำลองพฤติกรรมของ EA SNIPER CashFlow V1.68: ใส่ค่าพารามิเตอร์ 27 ตัวของ EA แล้วดูว่ากริดจะออกไม้แบบไหน ใช้ทุน/มาร์จิ้นเท่าไร ถ้าราคาวิ่งสวนทางจะเสียจุดไหน และธงเตือนความเสี่ยงมีอะไรบ้าง

ไม่ใช่: โปรแกรมเทรด · ตัว EA · การรับประกันกำไร · การบอกว่าค่าไหน "ดีที่สุด/ปลอดภัยที่สุด" โปรแกรมไม่จัดอันดับและไม่ให้คะแนน — แสดงแต่ตัวเลขจริงจากการคำนวณ ตัดสินใจเป็นของผู้ใช้ทุกครั้ง

3. เริ่มต้นใน 6 ขั้น (ทดลองแรก)

ขั้น 1 — หน้าแรก → กด เริ่มใช้ Calculator
ขั้น 2 — หน้า EA Settings → กดปุ่ม preset "Seller preset - Capital $500" (ค่าจะเปลี่ยนให้เอง)
ขั้น 3 — ช่อง Capital ใส่ 500 → กด บันทึกและตรวจสอบ → ดูผลตรวจ (ถ้าไม่มี ERROR จะมีลิงก์ "ถัดไป" ขึ้นมา)
ขั้น 4 — Grid Calculator → กด Calculate → ดูตารางไม้แต่ละชั้น + แผง Basket ด้านล่าง
ขั้น 5 — Worst Case → กด Simulate → ดูสถานการณ์ราคาวิ่งสวน 10–100 ดอลลาร์
ขั้น 6 — Risk Dashboard → กด Calculate → ดูสรุปความเสี่ยง + ธงเตือน

4. ทีละหน้า

4.1 EA Settings — ตั้งค่า EA และทุน

  • Preset 3 แบบ: Default (คู่มือ PDF) / ทุน $500 / ทุน $3000 — ค่าจริงจากเอกสารผู้ขาย (ปุ่มจะเขียนทับค่าปัจจุบันทันที)
  • Capital: เงินทุนที่ใช้จำลอง (USD)
  • Symbol: XAUUSD (default), BTCUSD, EURUSD — กด "ตั้งค่า Symbol Profile ละเอียด" เพื่อแก้ contract size / ราคาอ้างอิง / lot min-max-step ตามโบรกเกอร์จริง
  • พารามิเตอร์ 27 ตัว: กลุ่มพื้นฐาน (Grid, Lot) แสดงเสมอ · กลุ่มขั้นสูง (Trailing/Partial/Emergency/เวลา) ซ่อนอยู่ใน "พารามิเตอร์ขั้นสูง"
  • บันทึกและตรวจสอบ: ตรวจค่ากับข้อจำกัดโบรกเกอร์จริง (เช่น BaseLot 0.005 ต่ำกว่าขั้นต่ำ 0.01, leverage 0, เวลาผิดรูปแบบ) — ERROR ต้องแก้ก่อนคำนวณได้ · WARNING/INFO เป็นข้อควรรู้
  • รีเซ็ต: ล้างค่าทั้งหมดกลับ default

4.2 Grid Calculator — ตารางไม้รอบรอบ

เลือกฝั่ง (BUY/SELL), จำนวนชั้น (หรือ custom 1–500), แก้ค่าด่วน GridStep/BaseLot/Multiplier ได้เลยในหน้าเดียว แล้วกด Calculate

คอลัมน์ความหมาย
Levelลำดับไม้ที่ 1, 2, 3, … (ไม้ที่ 1 = ราคาเริ่มรอบ)
ระยะราคา ($)ระยะห่างจากราคาเริ่มต้น (= (ลำดับ−1) × GridStepUSD)
Entry Priceราคาที่ไม้นั้นจะถูกเปิด (BUY grid วิ่งลง / SELL grid วิ่งขึ้น)
Lot / Lot สะสมขนาดไม้ (โตตาม Multiplier) และผลรวมสะสมถึงชั้นนั้น
Exposure ($)มูลค่าพอร์ตที่ถือ (ราคา × ขนาด × contract size)
Floating P/L ($)กำไร/ขาดทุนลอยตัว ณ วินาทีที่ไม้ชั้นนั้นถูกเปิด — ยิ่งชั้นลึกยิ่งติดลบมาก (ค่าประมาณ ไม่รวม spread/commission/swap)
Margin ($)มาร์จิ้นที่ถูกล็อกถึงชั้นนั้น (คิดจาก leverage ที่ตั้ง)
Avg Entryราคาเฉลี่ยถ่วงน้ำหนักของไม้ที่ถืออยู่

แผง Basket / Partial Close (ล่างสุด): สรุปว่าถ้าราคาแช่อยู่จุดลึกสุดของ basket — ต้องเด้งกลับอีกกี่ดอลลาร์ถึงจะถึงจุด partial close / จุดปิดทั้งชุด (BasketCloseAllUSD) และหลัง partial แล้วเหลือ lot เท่าไร

4.3 Worst Case Simulator — ราคาวิ่งสวนทาง

  • เลือก "ระยะ movement" ได้หลายค่าพร้อมกัน (10/20/30/50/75/100 ดอลลาร์ หรือกำหนดเอง)
  • 3 สถานการณ์: BUY_ADVERSE (ราคาลง — กริด BUY ต่อไม้), SELL_ADVERSE (ราคาขึ้น), BOTH_SIDES (เปิดสองฝั่งพร้อมกันตามโมเดล)
  • ดู: จำนวนชั้นที่เปิด · lot รวม · Floating P/L · Equity คงเหลือ · DD% · Margin Level % (ต่ำ = เข้าใกล้โดน stop-out ตามกฎโบรกเกอร์)
  • คอลัมน์ Emergency: ถ้าติด ⚠ = ระยะเกิน EmergencyDistanceFromCycleUSD ที่ตั้งไว้ (รายละเอียดอยู่ในหมายเหตุใต้ตาราง)

4.4 Risk Dashboard — สรุปความเสี่ยง

รวมตัวเลขจากสถานการณ์อ้างอิง (movement + ความลึกกริด ตาม threshold ที่คุณตั้ง) เป็นการ์ดสรุป + Risk Flags เช่น HIGH ESTIMATED DD / LOW CAPITAL BUFFER / HIGH MARGIN USAGE / EMERGENCY STOP DISABLED — ธงทั้งหมดเทียบกับ threshold ของคุณเอง แก้ได้ทุกช่องในหน้านั้น (กด "ใช้ threshold ค่าเริ่มต้น" เพื่อกลับค่าเดิม) ธง 2 ตัวแรกที่ขึ้นเสมอ: MODEL ASSUMPTION และ EA BEHAVIOR NOT VERIFIED — เป็นการย้ำความซื่อสัตย์ของโมเดล ไม่ใช่สัญญาณอันตรายเฉพาะ

4.5 Set Builder — สร้างชุดค่าผสม

  • กรอกรายการค่าคั่นด้วยจุลภาค เช่น GridStep 5.0, 8.0 × Multiplier 1.08, 1.10, 1.20 × BaseLot 0.1 → ได้ทุก combination (2×3×1 = 6 ชุด) พร้อมผลคำนวณจริงทุกชุด
  • ตัวกรองไม่บังคับ: DD ≤ x%, Margin ≤ x%, ชั้น ≤ x, ไม้เดี่ยว ≤ x lot — แถวไหนไม่ผ่านจะบอกเหตุผล
  • ผลลัพธ์เรียงตามลำดับที่สร้าง ไม่มีการจัดอันดับ/คะแนน/ผู้ชนะ — คลิกแถวเพื่อดูคำเตือน validation ของชุดนั้น
  • จำกัด 300 ชุดต่อครั้ง (กันเครื่องทำงานหนัก)

4.6 Backtest Analyzer — นำเข้าผลทดสอบจริง

  • อัปโหลดไฟล์จาก MT5 Strategy Tester: CSV (deals export), HTML (report), TXT — ไม่เกิน 8MB
  • แสดง Net Profit, Profit Factor, Max DD, equity curve, ความลึกกริดสูงสุด, lot สูงสุด, ช่วงขาดทุนแรงสุด
  • ค่าไหนไม่มีในไฟล์จริง แสดง N/A — โปรแกรมไม่เดาค่า ไม่ประมาณเพิ่ม
  • ไฟล์ถูกอ่านเป็นข้อความเท่านั้น ไม่มีการรันโค้ดใด ๆ จากไฟล์ที่อัปโหลด

4.7 รายงาน (Reports)

เลือกส่วนที่จะรวม (Grid / Worst Case / Risk / Basket / แนบผล Backtest ล่าสุด) + รูปแบบ: JSON** (ข้อมูลดิบ) · CSV (ตาราง) · HTML — ไฟล์ HTML เปิดใน browser ได้และกด Ctrl+P พิมพ์เป็น PDF ได้ทันที ทุกรายงานมี assumption IDs + disclaimer ครบในตัว

4.8 Assumptions — ทะเบียนสมมติฐาน

ทุกตัวเลขในเว็บยึดสมมติฐานที่ระบุชัดเจน 4 สถานะ:

สถานะความหมาย
Verified / From-documentระบุไว้ในคู่มือ/เอกสารผู้ขาย
Observedยืนยันจากการบันทึกพฤติกรรม MT5 จริง
Model assumptionสมมติฐานของโมเดลจำลอง (ยังไม่ยืนยัน)
Unknownไม่มีข้อมูล — แสดงเป็น Unknown/N/A เสมอ ไม่เดา

ทุกหน้าผลการคำนวณมี "assumption chips" ให้คลิกดูรายละเอียดว่าตัวเลขชุดนั้นอิงอะไรบ้าง

5. ศัพท์ที่ควรรู้

คำความหมายสั้น ๆ
Grid / ชั้น (Level)การเปิดไม้เพิ่มเป็นขั้น ๆ เมื่อราคาวิ่งสวนทิศ (averaging)
GridStepUSDระยะห่างราคาระหว่างไม้ (ดอลลาร์ของราคาสินทรัพย์)
BaseLot / LotMultiplierขนาดไม้แรก / ตัวคูณโตของไม้ถัดไป (โมเดล: lot = BaseLot × Multiplier^(ชั้น−1))
Basket Closeปิดทั้งชุดเมื่อกำไรรวมสุทธิถึง BasketCloseAllUSD
Partial Closeปิดบางส่วน (ตาม %) เมื่อกำไรรวมถึงจุด trigger
Floating P/Lกำไร/ขาดทุนลอยตัวของไม้ที่ยังถือ
Equityทุน + กำไร/ขาดทุนลอยตัว
DD (Drawdown)% ที่ equity ต่ำกว่าจุดสูงสุด — ยิ่งสูงยิ่งเสี่ยง
Margin / Margin Level %เงินค้ำที่ถูกล็อก / (Equity ÷ Margin × 100) — ต่ำกว่าระดับโบรกเกอร์ = เสี่ยง stop-out ถูกปิดเอง
Exposureมูลค่าพอร์ตที่เปิดค้าง (ยังไม่ใช่ความเสี่ยงโดยตัวมันเอง)
Emergency Stopกลไกฉุกเฉินของ EA เมื่อราคาวิ่งเกินระยะที่ตั้ง (ปิดอยู่โดย default)

6. คำถามที่พบบ่อย

เว็บออนไลน์เปิดช้า / ขึ้นรอเปิดครั้งแรก?

ปกติของโหมดฟรี (หลับหลังไม่มีคนใช้ 15 นาที) รอสัก 30–60 วินาทีแล้วรีเฟรช — ถ้าเข้าไม่ได้เลยให้ลอง: https://sniper-web.onrender.com/api/health

เว็บในเครื่องเปิดไม่ได้?

กดไอคอน SNIPER Web - Start บน Desktop ก่อน แล้วรีเฟรชหน้าเว็บ (F5) · ยังไม่ได้ → กด SNIPER Web - Stop แล้ว Start ใหม่

ค่าที่กรอกหาย?

ค่าถูกจำใน browser ที่ใช้ (เคลียร์ประวัติ/ใช้โหมดไม่ระบุตัวตน = หาย) — หน้า EA Settings มีปุ่ม "รีเซ็ตเป็นค่าเริ่มต้น" เมื่อไหร่ก็ได้

ทำไม lot ไม้ถัดไปไม่ตรงกับ EA จริงที่เห็นใน MT5?

สูตร lot progression เป็น MODEL ASSUMPTION (ดูหน้า Assumptions) — ถ้ามีข้อมูลจริงจาก MT5 ให้เทียบผ่านหน้า Behavior Verification ของโปรแกรม Desktop เพื่อปรับสถานะสมมติฐาน

เอาผลไปให้คนอื่นดูยังไง?

หน้ารายงาน → HTML → "เปิด HTML ในแท็บใหม่" → Ctrl+P พิมพ์/บันทึก PDF ส่งต่อได้ หรือส่งลิงก์เว็บให้เขาลองเอง

ข้อมูลปลอดภัยไหม?

เว็บคำนวณล้วน ๆ: ไม่มี login ไม่มีการเก็บข้อมูลส่วนตัวบน server (ค่าพารามิเตอร์อยู่แค่ใน browser คุณ) ไม่มีคำสั่งซื้อขาย · ไฟล์ที่อัปโหลดถูกอ่านเป็นข้อความแล้วลบทันที จำกัดชนิด/ขนาด

7. ข้อจำกัดที่ควรทราบ

  • การคำนวณ ไม่รวม spread / commission / swap ของโบรกเกอร์จริง (ระบุไว้ใน PL_CONVERSION_ASSUMPTION_001)
  • จำนวนชั้นกริดสูงสุดข้างใน EA จริงไม่มีใครรู้ (Unknown) — เว็บให้คุณเลือกความลึกที่จะวิเคราะห์เอง
  • พฤติกรรมข้างใน .ex5 ยืนยันไม่ได้ (ห้าม decompile) — ทุกผลคือโมเดลจำลอง ควรตรวจกับ Strategy Tester จริงเสมอ
  • เว็บออนไลน์โหมดฟร่ีมีขีดจำกัดทรัพยากร (ตารางเกิน 300 ชุด/ครั้ง ฯลฯ)
